# Free software commitment

OpenCarDueDiligence is an open-source public-interest project. The official
project and its maintainers do not offer:

- a paid, premium, enterprise, or subscription edition;
- feature gates, advertising, referral fees, or data-brokerage revenue;
- a proprietary alternative license for the application; or
- a required hosted LLM, paid API key, account, or commercial data feed.

The deterministic buyer workflow runs locally under AGPL-3.0-or-later. The
plugin SDK remains Apache-2.0 so independent free/open integrations can be
built without changing the application's license. First-party rule and
knowledge data remains CC BY-SA 4.0 unless its manifest says otherwise.

This commitment is about the official project. It does not add a
non-commercial restriction to the AGPL: recipients retain every right the
license grants, including the right to provide paid hosting, installation, or
support while complying with that license. Those third parties do not become
an official paid edition of OpenCarDueDiligence.

## Costs outside the software

Using the software cannot make a vehicle transaction itself cost-free. An
independent pre-purchase inspection, insurance, tax, registration, permits,
towing, repairs, an OBD adapter, optional vehicle-history reports, and hosting
infrastructure may cost money. OpenCarDueDiligence does not sell, require,
receive commission from, or designate an exclusive provider for any of them.

Unknown evidence remains unknown. The free-software commitment will never be
used to weaken a safety, title, insurance, or legal-drive-away gate merely to
avoid an external professional or government cost.
